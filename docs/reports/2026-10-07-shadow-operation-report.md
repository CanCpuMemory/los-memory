- 14 天窗口的**正式**判定必须在窗口满 14 天后重跑本脚本；本报告若早于该时点，只作为滚动观察，不能当作门槛已通过。

## 8. 交付的机制（本次新增）

| 机制 | 落点 | 验证 |
| --- | --- | --- |
| 运行报告生成器 | `scripts/shadow_report.py report` | 本文件即其输出（10.97 天窗口，3079 轮） |
| 告警评估 | `scripts/shadow_report.py alert` | 7 个阈值逐条合成输入验证全部触发，健康基线静默 |
| 告警定时 | M1 launchd `com.echerlos.los-memory-shadow-alert`，每小时 | 已 bootstrap，实跑 exit 0、`alerts: []` |
| 告警台账 | `~/.local/share/los-memory-shadow/alerts.jsonl`（0600） | 每次评估追加一条 |
| 日志轮转 | M3 launchd `co.los.memory-shadow-maintenance`，每日 05:10 | 已 bootstrap；当前 515 KB < 8 MiB 上限，未轮转 |
| 轮转实现 | `python3 -m memory_tool.shadow rotatelog --max-bytes 8388608 --keep 5` | copy-truncate 保 inode，launchd 的 fd 不被写丢；同秒多次轮转不覆盖（单元测试钉住） |

告警阈值（都是设计文档里写明的预算，不是调出来的经验值）：

| 代码 | 条件 | 依据 |
| --- | --- | --- |
| `stale_verification` | 最旧验证 > 24h | 迁移门槛 1 |
| `sync_silent` | 距最近一轮 > 30 min | 300 s 节奏 + 余量，判断任务是否还被调度 |
| `sync_errors` | 滚动 24h 有失败轮 | P1 计量 |
| `index_not_ready` | `search_index.state != ready` | 防止"索引没建"被答成"没有记忆" |
| `contract_empty` | 无任何记录带 project | 防止契约字段静默消失 |
| `manifest_shrank` | 清单较上一轮跌超 5% | 防止主库异常或源端范围变化被当成正常 |
| `backup_stale` / `no_offhost_backup` | 异机备份 > 24h 或无台账 | RPO 门槛 |
